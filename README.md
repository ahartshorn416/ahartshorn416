I'm a Data Science Master's candidate (expected June 2026) with hands-on experience building end-to-end analytics pipelines at scale — including a 16M+ row machine learning project using U.S. Census data. My background in legal operations and academic administration gives me an edge in data governance, compliance, and communicating with non-technical audiences.
